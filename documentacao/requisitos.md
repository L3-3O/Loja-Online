# Requisitos

## Requisitos Funcionais

### Catálogo de Produtos

- O sistema deverá listar os produtos disponíveis.
- O sistema deverá permitir pesquisar produtos pelo nome.

### Carrinho de Compras

- O sistema deverá permitir adicionar produtos ao carrinho.
- O sistema deverá permitir alterar a quantidade de um item.
- O sistema deverá permitir remover um item do carrinho.

### Autenticação

- O sistema deverá permitir login do cliente com Google.

### Endereços

- O sistema deverá permitir cadastrar endereços.

### Pedidos

- O sistema deverá registrar pedidos.

### Pagamentos

- O sistema deverá processar pagamentos.

### Notificações

- O sistema deverá enviar uma confirmação por e-mail.

---

## Requisitos Não Funcionais

### Compatibilidade

- A aplicação deverá funcionar em computadores e celulares.

### Interface

- As páginas deverão possuir layout responsivo.

### Banco de Dados

- As consultas ao banco deverão utilizar *prepared statements*.

### Segurança

- As senhas administrativas não deverão ser armazenadas em texto simples.
- A aplicação publicada deverá utilizar uma conexão HTTPS.
- Os formulários deverão validar os dados no servidor.
- As mensagens de erro não deverão revelar informações do banco de dados.
